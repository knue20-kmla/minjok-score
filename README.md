# 민족사관고등학교 1단계 성적 계산기

2027학년도 민족사관고등학교 신입생 모집요강을 기준으로 중학교 4개 학기, 7개 교과 영역의 성취도와 출결을 입력해 1단계 예상 성적을 계산하는 정적 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 웹서버로 제공하면 됩니다.

## 관리자 비밀번호

- 최초 `관리자 화면` 접근 시 비밀번호를 설정합니다.
- 비밀번호 원문은 저장하지 않고 SHA-256 해시만 현재 브라우저의 `localStorage`에 저장합니다.
- 관리자 화면 접근 권한은 현재 브라우저 세션의 `sessionStorage`로 잠금 처리합니다.
- 관리자 화면에서 비밀번호를 변경하거나 잠글 수 있습니다.

이 앱은 서버 없는 정적 GitHub Pages 앱이므로 관리자 비밀번호는 화면 잠금용입니다. 사용자가 개발자 도구나 브라우저 저장소를 직접 조작하는 것을 막는 서버 인증 기능은 아닙니다. 여러 사용자가 공유하는 운영자 권한 관리가 필요하면 별도 백엔드 인증이 필요합니다.

## 관리자 Gmail로 성적표 PDF 보내기

GitHub Pages에서 Gmail 계정으로 직접 메일을 발송할 수는 없으므로, 관리자 Google 계정에서 Google Apps Script 웹앱을 한 번 배포해야 합니다. Apps Script는 성적표 Google 문서를 임시 생성하고 PDF로 변환한 뒤, 웹앱을 배포한 관리자 Gmail 계정에서 학생 이메일로 첨부 발송합니다.

1. 관리자 Google 계정으로 Apps Script를 새로 만듭니다.
2. 이 저장소의 `apps-script/Code.gs` 내용을 Apps Script 편집기에 붙여넣습니다.
3. 파일 상단의 `APP_TOKEN`을 충분히 긴 임의 문자열로 변경합니다.
4. `배포 > 새 배포`에서 유형을 `웹 앱`으로 선택합니다.
5. 실행 주체는 `나`, 액세스 권한은 `모든 사용자`로 설정하고 배포합니다.
6. 최초 실행 시 Google Docs, Drive, Gmail 권한을 승인합니다.
7. 발급된 웹앱 URL과 `APP_TOKEN`을 앱의 `관리자 화면 > PDF 이메일 자동 발송 설정`에 입력하고 `설정 저장`을 누릅니다.

학생 화면에서 `결과 보내기 (이메일)`을 누르면 입력한 주소로 PDF 발송 요청이 전송됩니다. 실제 발송은 Apps Script를 실행하는 관리자 계정에서 이루어집니다. Gmail/Apps Script의 일일 발송 한도와 Google 계정 정책이 적용되며, URL과 토큰은 이 브라우저의 `localStorage`에 저장됩니다.

## 배포

GitHub 저장소 루트에 이 디렉터리의 파일을 올리고 GitHub Pages를 `main` 브랜치의 `/ (root)`에서 활성화하면 됩니다.
